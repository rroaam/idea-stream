# idea:stream

**Seeds growing into forests.** A calm place to plant creative ideas and watch them grow.

Most idea tools reward volume. idea:stream rewards patience: capture a seed, revisit it, and let the good ones grow on their own timeline.

**Live:** https://idea-stream-eta.vercel.app

## Run
```bash
npm install
npm run dev
```

**Stack:** Next.js · Vercel
